# Wooden Bear Ads Studio

Landing page for [woodenbear.studio](https://woodenbear.studio) — AI UGC ads for DTC brands on Shopify.

## What

A single-file static landing built with Tailwind CSS (via CDN). Deployed via Cloudflare Pages.

- **Live chat:** Tawk.to widget, opens from any CTA button
- **Stack:** HTML + Tailwind CDN + Google Fonts
- **Build:** none required — pure static
- **Hosting:** Cloudflare Pages (free tier)

## Files

- `index.html` — the landing
- `wooden_bear_logo.jpg` — brand logo (header + hero)

## Deploy

Auto-deploys on push to `main` via Cloudflare Pages connected to this repo.
